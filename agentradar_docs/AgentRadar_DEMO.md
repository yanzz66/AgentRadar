# AgentRadar — 功能演示与验收指南

本指南覆盖 AgentRadar 的 GitHub 仓库检索、候选筛选、证据追踪、规则核验、报告生成及结构一致性评估。演示数据可能随 GitHub 仓库状态变化；历史结果与实时任务应明确区分。

## 1. 运行条件

项目采用本地 Ollama/Qwen3:8b、FastAPI 和 Streamlit。启动应用前检查服务：

```powershell
Invoke-RestMethod http://127.0.0.1:11434/api/tags
Invoke-RestMethod http://127.0.0.1:8000/api/health
```

打开 `http://localhost:8501` 进入 AgentRadar。网络不可用时，可查看此前生成并经过脱敏的报告文件；这类文件属于历史样例，不代表实时检索结果。

## 2. 创建研究任务

**示例需求**

> 基于 Python 开发 Browser Agent，优先考虑本地部署、MCP 集成和二次开发便利性。检索值得进一步评估的 GitHub 项目，并指出仍需确认的能力。

**GitHub 查询条件**

```text
browser agent language:Python archived:false
```

在界面中将候选项目数设为 `5`，创建研究任务。接口返回任务 ID；研究进度及结果可通过该 ID 查询。

当前版本由用户明确指定 GitHub 搜索表达式，尚不具备将任意自然语言需求完整转换成所有 GitHub 筛选条件的能力。

## 3. 候选项目筛选与评分

在“候选项目对比”界面查看仓库名称、元数据状态、Stars、主要语言、许可证和最近推送时间，并展开对应的评分依据。

当前元数据评分由以下部分组成：

| 维度 | 分值 | 含义 |
|---|---:|---|
| 维护活跃度 | 50 | 根据仓库最近更新情况估计活跃程度 |
| 社区关注度 | 30 | 基于 Stars 等仓库元数据 |
| 许可证字段完整性 | 20 | 检查许可证信息是否可获取 |
| **总计** | **100** | 仅用于候选项目初筛与排序 |

主要语言、归档状态等条件先用于硬约束筛选。该分数不衡量程序性能，也不能证明候选项目已满足 MCP、本地部署或商业使用等全部需求。

## 4. 证据追踪与规则核验

在 Evidence Explorer 中选择候选仓库，查看：

- Evidence ID、来源 URL、内容快照和采集时间；
- 证据与 Claim（待核验主张）的关联；
- `supported`、`contradicted`、`insufficient` 三类规则核验结果；
- 对部分元数据缺口触发的有界补查记录。

证据编号和 SHA-256 用于支持追踪及一致性检查，不等同于对所有事实的真实性担保。核验器主要处理可结构化表示的事实，尚未实现通用语义事实核验。

## 5. 研究报告

在“完整研究报告”界面查看候选项目分析、风险、待验证事项及来源链接，并下载 Markdown 报告。

报告由本地 Qwen3:8b 根据已提供的资料生成。模型解释性文字尚未经过逐句自动事实核验；关于架构、MCP 兼容性和部署方式的结论仍需结合官方文档、源码或实际测试确认。

## 6. 结构一致性评估

评估脚本会在本地生成结果文件，默认位于：

```text
output/agentradar/evaluation/
```

可检查的结构指标包括证据哈希一致性、Claim 引用有效性、核验状态一致性、候选证据覆盖及报告引用覆盖。运行任务数和实际耗时以生成的 JSON/Markdown 产物为准。

结构一致性指标不等同于事实准确率或幻觉率。人工报告内容质量检查不属于当前已完成的自动化评估范围。

## 7. 设计选择与已知限制

| 设计选择 | 作用与边界 |
|---|---|
| 规则式元数据评分 | 输出可解释、可重复、可单元测试；不是技术能力的综合评级 |
| Evidence Store | 保留来源和内容快照，支持追溯；证据存在不代表主张已被证实 |
| 有界 Replanning | 针对明确的缺失字段进行有限次数的补查；不同于无条件重复请求 |
| FastAPI + Streamlit | 分离任务执行接口与可视化界面 |
| 本地 Qwen3 | 对检索结果进行整理与分析；自然语言内容仍需审查 |

当前尚待完善的能力包括：补查结果与评分输入的进一步整合、多源检索主链的端到端验证、任务重启恢复，以及人工标注的报告质量评估。

## 8. 项目来源

AgentRadar 基于开源项目 [GPT Researcher](https://github.com/assafelovic/gpt-researcher) 扩展。有关扩展模块、架构和运行方式，参见 [AgentRadar 项目说明](AgentRadar_README.md)；上游原有功能及许可证归属保持不变。
